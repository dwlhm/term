# Agents and `term`

Shells in term are sessions you can drive with `term session …`. The agent guide
is the bundled skill — read it instead of guessing:

```bash
term skill show          # how to run commands, send and take requests, wait, observe
term session --help      # every verb; term session <verb> --help for its flags
term session whoami      # your own session id ($TERM_SESSION_ID)
```

`term session` is not Luvus: do not use the luvus CLI or skill for term sessions.
