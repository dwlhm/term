Features

Built from first principles

Every stage is measured before it ships. Empirical percentiles, not intuition, decide which data structure or GPU pass survives.

  • 01Memory

    Zero steady-state allocations

    Input rings, grapheme pools, the shape cache and GPU atlas slots are allocated up front. Once running, normal frame cycles perform zero heap allocations.

  • 02Renderer

    Adaptive GPU rendering

    Each frame chooses between instance, compute-tile and fullscreen strategies to match the workload. Carve-outs keep single-cell updates and scrolling off the heavy GPU passes.

  • 03Damage

    Only changed cells are uploaded

    Damage tracking narrows work from cell to span to row, so only mutated cells reach the GPU. Scrollback advances through ring offsets in constant time, with no memory copying.

  • 04Protocols

    Modern terminal protocols

    Term speaks Kitty graphics and keyboard, Sixel, OSC 8 hyperlinks and synchronized output. Alternate screen, DEC graphics and complete SGR keep vim, htop and tmux intact.

  • 05Text

    Unicode & typography

    Extended grapheme clusters cover combining marks, ZWJ sequences and wide CJK glyphs. Multi-tier fallback spans symbols, Arabic and color emoji, while glyphs rasterize on a background worker.

  • 06Workspace

    Native feel

    Tabs, splits, in-terminal search and JSON5 configuration share one window. Session persistence keeps long-running work alive after a window closes.

Install

Get started

Download a prebuilt release, or build from source.

Install

Prebuilt releases are available for macOS and Linux.

macOS

Download Term.dmg from Releases, open it, and drag Term.app into /Applications.

Linux

Download the Linux tarball from Releases, extract it, then run:

sudo ./install.sh

Build from source

Requires the Odin compiler (dev-2026-08 or newer) on your PATH and make.

macOS dependencies

brew install sdl3 freetype harfbuzz

Build and run

make term
./bin/term
